# Separate-context review, 30 October 2026

This was a read-only review by a fresh agent context that was given the branch and no conversation history. It is a separate context, not Josh's or an external reviewer's acceptance, and it used the same model family. It ran the tests (214 passed at the time), lint and types and found no high-severity defect. Findings and dispositions are kept here.

| Severity | Finding | Disposition |
|---|---|---|
| Medium | Power BI numeric measures show `vsi_max` 6 without the `>` bound; only HTML did | Fixed in scope. The comparison table and visual now carry `baseline_display`, `candidate_display` and states for native reports, and the docs state that numeric measures and cards hold the raw vendor value |
| Medium | PDF leak check cannot see glyph-encoded text; 8.3 short names could slip | Fixed. Source HTML is refused if it shows the report folder, home or temp paths (several spellings); with `pypdf` the extracted text is rescanned. Docs state the limit |

| Medium | Killed task left a lock that blocked every later run | Fixed: reclaimed after `lock_stale_hours` (default 3) and recorded; unreadable locks are never reclaimed; status reports an overdue lock |

| Medium | Scheduler script mangled an `-OutRoot` with a trailing backslash | Fixed |
