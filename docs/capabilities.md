Minimal resource requests fail with HTTP 500 when optional sorting is omitted. Explicit `orderBy=timestamp` recovered requests on the observed appliance; Swagger definitions match the checked-in operation. Selected Load captures contain successful empty resource envelopes. Broader Continuous discovery found populated retained resource data with successful, failed and unfinished execution evidence. Current definitions/sample timestamps do not establish healthy active collection; new observations remain pending. Earlier failed captures remain partial and immutable. Empty resources cannot support CPU/memory conclusions. Default comparisons reject partial captures; explicit `timer-only` policy permits only complete timing/failure evidence for every selected result when session-metric acquisition alone failed. Retained observations are not independent devices.

The API does not declare every timer unit. Unknown units, historical collector settings and retention gaps remain labeled. SetTimer can represent resources or categorical sentinels; declared status values cannot be averaged. Native EUX/VSImax states and bounds remain vendor evidence without a toolkit scoring algorithm. Names do not establish OS identity, independence or causality.

Reports support metric/group tables, unit filters, change charts and coverage. Finite reports show numeric timer/resource rows and endpoint outcomes. Manifests record unresolved/nullable timer-execution references separately from acquisition completeness. HTML relative-change scale is dimensionless. Power BI source-unit measures guard unit selection. Generation, schema/reference checks, M parsing, Desktop opening, refresh and reconciliation are separate evidence states. No PBIT is fabricated.

Native PDF retrieval is implemented and exercised for the documented completed Application GET route, with binary/hash/page validation. It creates no report job and claims no native multi-result Load/Continuous PDF path. Public-only focused review and synthetic Claude native skill invocation are distinct from Desktop/runtime/platform acceptance.
